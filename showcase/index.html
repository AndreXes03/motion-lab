Get Motion Lab ↗

Tested on macOS · Node.js 22.12+ · Google Chrome
Internet required for the first installation.

Start the studio
git clone https://github.com/AndreXes03/motion-lab.git
cd motion-lab
npm ci
npm run viewer

Your files and renders stay on your Mac.
