Lo studio locale

Studio

Timeline, preset, camera, look ed export.

Compositing: profondità di campo 3D, occlusione ambientale, bloom, alte luci, aberrazione cromatica, vignettatura e distorsione lente. Grana dopo il motion blur e overlay 2D sopra il render.

Sound design: SFX legati ai movimenti 2D/3D, moduli regolabili e musica procedurale.

Installazione

macOS, Node.js 22.12+ e Google Chrome. Internet serve per la prima installazione.

git clone https://github.com/AndreXes03/motion-lab.git
cd motion-lab
npm ci
npm run viewer

Verificato su macOS; Windows e Linux richiedono adattamenti. Verifiche e limiti · Licenze degli asset
