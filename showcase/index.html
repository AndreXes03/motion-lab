Studio

Timeline, presets, camera, look and export.

Sound design: Movement-driven 2D/3D SFX, adjustable modules and procedural music.

Setup

macOS, Node.js 22.12+ and Google Chrome. Internet is needed for the first installation.

git clone https://github.com/AndreXes03/motion-lab.git
cd motion-lab
npm ci
npm run viewer

Tested on macOS; Windows and Linux need adaptation. Checks and limits · Asset licenses
