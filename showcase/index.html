SOUND

Movement has a voice.

Build procedural music and movement-driven 2D or 3D effects alongside the scene.

Sound design guide ↗

In supported browsers, the public Studio exports browser-rendered video at 720p or 1080p, PNG frames and JSON recipes. MP4 is available when the browser supports its encoder; otherwise it offers WebM. This uses the real-time Three.js/Canvas path. Blender Cycles requires Motion Lab running on your computer with Blender installed; the current adapter supports PULSE only. This website does not run Cycles or server-side renders. Mixed shots require prepared render inputs and a local compositing plan.

FOR THE CURIOUS

A recipe you can read.

Scenes are parameterized code and JSON, sampled at an exact time. Motion curves can be grouped by camera or object, with one chosen shot window at a time. The source stays open when you want to go beyond the controls.

Browse scene source ↗Browse project recipes ↗

  "scene": "bax",
  "animation": {
    "version": 1,
    "enabled": true,
    "rate": 1,
    "groups": {

        "start": 0, "end": 2.2,
        "rate": 1,
