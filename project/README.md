# Recipes and tracks

Settings are readable JSON, editable by an agent and versioned with Git.

| File or folder | Contents |
| --- | --- |
| [look.json](look.json) | Camera, lights, surfaces, lens and finishing |
| [motion.json](motion.json) | Camera and object tracks |
| [studio.json](studio.json) | Projects, controls, presets and viewer moments |
| [graphics.json](graphics.json) | Procedural graphics settings |
| [lighting-presets.json](lighting-presets.json) | Lighting setups |
| [looks/](looks/) | Complete look variants |
| [references.json](references.json) | Reference collection; empty in this repository |

Saved versions, history and personal references are created locally and excluded from Git. [Agent workflow](../docs/AGENT_WORKFLOW.md).
