# Ricette e tracce

Le impostazioni sono JSON leggibili, modificabili da un agente e versionabili con Git.

| File o cartella | Contenuto |
| --- | --- |
| [look.json](look.json) | Camera, luci, superfici, lente e finitura |
| [motion.json](motion.json) | Tracce di camera e oggetti |
| [studio.json](studio.json) | Progetti, controlli, preset e momenti del viewer |
| [graphics.json](graphics.json) | Impostazioni della grafica procedurale |
| [lighting-presets.json](lighting-presets.json) | Schemi luce |
| [looks/](looks/) | Varianti complete del look |
| [references.json](references.json) | Raccolta reference; vuota nella pubblicazione |

Le versioni salvate dal viewer, la cronologia e le reference personali vengono create localmente ed escluse da Git. [Workflow per agenti](../docs/AGENT_WORKFLOW.md).
