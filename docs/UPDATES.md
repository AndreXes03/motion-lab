# Mac updates

The app shortcut, `npm run studio`, `npm run setup` and **Setup Framevolve.command** check the official GitHub repository when starting. A new compatible version offers **Update** or **Later**. Later keeps the installed version and the offer returns on a subsequent launch. No account, model call, Git installation or administrator password is required for ZIP updates. Network failures leave the installed version usable.

Close Studio before updating: an existing session or render is preserved and updates are deferred. Source files are downloaded from an immutable official commit and verified against Git blob hashes. The installed distribution baseline distinguishes upstream changes from local edits. Unrelated local edits, projects, memory, outputs and settings stay in place. If upstream and local edits conflict, nothing is replaced; the dialog names the affected files. Keep the project and reconcile it with your coding agent, or download a separate copy. Git checkouts must be on clean main and only fast-forward after confirmation.

Updates are staged, with previous files backed up under `.motion-cache/update-backups/`. Dependency changes trigger npm installation. A failed installation rolls source back and restores the old dependencies. If rollback cannot finish or a process is interrupted, launch is blocked rather than using a partial update. Keep the backups; close Studio and run `node scripts/recover-update.mjs` to restore source and dependencies. If an update process was forcibly killed before its transaction began, remove `.motion-cache/distribution-update.lock` only after confirming no update is running, then reopen setup. Recovery never intentionally overwrites a newer local edit.

**Older ZIP copies need this new download once.** They cannot acquire updater code that was absent from their original version. Keep the downloaded folder: the application shortcut points to it. The setup downloads the latest source updates before opening its installation screen; the setup file itself is included in subsequent updates.
