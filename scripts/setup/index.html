Your feedback can improve Framevolve.

If you enable this option, your agent can save a memory in this project: feedback, its interpretation, changes made, before/after notes and your response.

The memory helps retain approved creative choices. If you choose to share selected examples with Andrea at framevolve.app@gmail.com, they can help improve Framevolve’s agent instructions and workflows.

Nothing is uploaded or emailed automatically. In Studio, you can review and edit a report, download it, and open an email draft. You attach the report and send it yourself.

Videos, images, full conversations and credentials are not attached. Feedback text may contain client details: remove them before sharing. Your AI provider’s own data handling is separate.

You can turn this off or delete the memory from Studio → Feedback memory. Turning it off stops new entries and keeps existing ones until you delete them. The project and live checklist continue working either way.
